Honeycrumb Bake House - website
Developed by Fiza

How to use
1. Open index.html in any browser. It needs internet only for the Google Fonts.
2. Change the WhatsApp number, Instagram handle and city in index.html.
   Search for "var CONFIG" near the bottom of the file.
   WhatsApp number format: country code, no plus sign, no spaces (example 923001234567).
3. Change item names and prices in the ITEMS list just below CONFIG.
4. To publish it, upload index.html to any static host (Netlify, GitHub Pages, Vercel).
